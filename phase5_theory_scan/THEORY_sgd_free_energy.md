# SGD 自由能框架的理论推导与可检验预测

本文档对应补充任务 1（自由能框架的独立验证）与任务 2（熵产准则的理论
基础）。推导从 SGD 更新规则出发，给出 ΔF 的解析展开、dF/dt 对 η 的标度
预测、非平衡熵产率的理论形式，以及 dS/dt 噪声方差的来源分解，并逐条列
出可被 phase5/phase6 数据检验的预测。文末明确列出假设与已知失效处。

记号：θ ∈ R^d 为全部可训练参数；U(θ) 为训练损失（含权衰减时为正则化能量
U = L_data + (λ/2)‖θ‖²）；B 为批量大小；单样本梯度协方差

  Σ(θ) = Cov_z[∇ℓ(θ; z)]，   批量梯度噪声 ξ_B，E[ξ_B]=0，Cov(ξ_B)=Σ/B。

实验序参量 S 为权重取值直方图（100 个固定 bin）的归一化香农熵，
S = −Σ_i p_i ln p_i / ln L；自由能定义 F = U − T·S，按阶段三取 T = η。

## 1. 任务 1：ΔF 的一阶展开与 dF/dt 的 η 标度

### 1.1 SGD 的 Euler–Maruyama 形式

SGD 更新（λ=0 时；AdamW 见 §4  caveat）：

  θ_{t+1} = θ_t − η g_B(θ_t)，  g_B = g + ξ_B，g = ∇U，E ξ_B = 0。

### 1.2 能量变化 ΔU

对 U(θ − η g_B) 作二阶 Taylor 展开：

  ΔU = −η g_B^T g + (η²/2) g_B^T H g_B + O(η³)，H = ∇²U。

对批量噪声取期望（E ξ=0，E[ξ ξ^T]=Σ/B）：

  **E[ΔU] = −η G + (η²/2)·tr[ H( g g^T + Σ/B )] + O(η³)，**  (1)

其中 G = g^T g。两项物理含义：

* −ηG：确定性梯度下降的能量耗散（drift，阶 η）；
* +(η²/2) tr(…)：离散更新的"过热"项（阶 η²），由梯度方向曲率与梯度噪声
  共同贡献。稳态（E[ΔU]=0）要求二者平衡，这要求高曲率/高噪声，即
  临界点附近的条件。

### 1.3 熵变化 ΔS 与自由能变化 ΔF

F = U − T S，单个 run 内 T=η 固定，故

  **E[ΔF] = E[ΔU] − η E[ΔS]。**  (2)

对直方图熵 S(θ)（它是 θ 的可微泛函，bin 占用不变时），链式法则：

  ΔS = −η g_B^T s + (η²/2) g_B^T H_S g_B + …，s ≡ ∇S。

取期望：

  E[ΔS] = −η g^T s + (η²/2) tr[H_S(gg^T+Σ/B)] + …。(3)

将 (1)(3) 代入 (2)，得到**逐阶解析表达式**：

  E[ΔF] = −η (g^T g − s^T g … 项需在统一熵归一化下理解)
          + (η²/2){ tr[H(gg^T+Σ/B)] − tr[H_S(gg^T+Σ/B)] } + O(η³)。

为得到干净的可检验形式，用 SDE 连续极限更方便（1.4）。

### 1.4 连续极限、Langevin 对应与标度预测

小 η 下 SGD 收敛到过阻尼 Langevin SDE：

  dθ = −η g dt + √(η/B) Σ^{1/2} dW_t。

其平稳分布为 Gibbs 型 p_*(θ) ∝ exp(−U/T_eff)，
**T_eff = η·tr Σ / (B·tr H_Σ)**（各向同性近似下 T_eff = η/B，
噪声温度正比于 η）。阶段三取 T = η 即吸收了 1/B 常数到温度单位。

自由能（平均）平衡速率：

  **dF/dt ≈ −η G + η² Q − η dS/dt，**
  Q ≡ (1/2) tr[H(gg^T+Σ/B)]。  (4)

当训练进入准稳态（U、S 均在平台附近缓慢漂移，dS/dt ≈ 0）：

  dF/dt ≈ −η G + η² Q = −η G (1 − η/η_c*)，  (5)

其中

  **η_c* = G/Q = 2G / tr[H(gg^T+Σ/B)]。** (6)

由此得到三个可检验预测：

* **P1（线性标度）**：稳态下 dF/dt / η（或 dU/dt / η）对 η 作图应近似
  线性，斜率为正（Q），截距为负（−G）；在 η = η_c* 处过零。
  η < η_c*：F 持续下降（有序相的能量主导侧）；η > η_c*：二阶项使
  F 不再能被梯度下降压低，体系停在高 S、高 U 的无序平台。
* **P2（临界 η 的独立估计）**：η_c* 完全由局域量 G、H、Σ/B 构成，不
  使用任何终态拟合，可逐 checkpoint 计算轨迹平均 η_c*(t)；它应与
  序参量拟合得到的 η_c ≈ 0.030（phase3d）在数量级/数值上一致。
  这是对"热力学相变"解释的**独立**（非循环）检验。
* **P3（幂律区）**：紧邻 η_c* 上方，令 ε = η − η_c*，
  dF/dt ≈ −G·ε（线性尖点）；序参量 m = 1−S 由熵-能量竞争的鞍结分叉
  决定，平均场下 m ∝ ε^{1/2}（β_MF = 1/2）。phase3d 实测 β≈0.26
  显著小于 1/2——若新数据维持 β<1/2，则简单平均场不适用，需引用
  涨落/约束修正，而不能反过来用平均场解释数据。

### 1.5 数据如何检验（phase5 记录的量）

每 1000 步用**独立 probe 批**（独立 RNG，不做优化步）记录：

  G = ‖(g1+g2)/2‖²，  tr C = ‖g1−g2‖²/2（C 即 Σ/B 的迹的无偏估计），
  tr H（1 探针 Rademacher + 中心差分 HVP，ε=10⁻³，因本机构建
  MaxPool2d 不支持二阶 autograd）。

检验口径（分析脚本 `phase5_theory_analysis.py`）：

1. 实测 ΔU/Δt（区间均值 U 的有限差分）对比式 (1)：
   * 领头阶 −η G（无需近似）；
   * 二阶修正用各向同性代理 tr(HM) ≈ (trH/d)·tr M，
     M = gg^T+Σ/B，即 (η²/2)(trH/d)(G + trC)。
   报告逐 η 的相关系数、RMSE 与两项各自占比。
2. 式 (5)(6)：准稳态窗口（后 50% checkpoints）内 G、Q、η_c*(t) 的
   seed 平均；η_c* 与重拟合 η_c（`phase5d_critical_dense.py`）比较。
3. dF/dt 对 η 的线性度（P1），及过零点。

## 2. 任务 2：熵产准则的非平衡热力学

### 2.1 系统、热浴、熵产来源

* **系统**：网络权重 θ（构型空间 R^d）。
* **热浴**：小批量数据流。每次采样 z_t∼P_data 注入一个外生随机力
  ξ_B(t)，它不依赖 θ、无记忆、均值为零——正是热浴噪声的定义。
  数据本身的信息熵在训练协议下固定，不进入账本。
* **功**：优化器沿 −g_B 做功。
* **熵产的两个来源**：
  (a) 不可逆梯度耗散（摩擦生热，Q_bath）；
  (b) 有限批量噪声引起的构型扩散（系统构型熵 S_sys 的变化）。

### 2.2 热、熵流与熵产率

Langevin 账本（Sekimoto 随机能学）：单步传入热浴的热（摩擦功扣除
离散修正）

  q ≈ η G − (η²/2) tr[H(gg^T+Σ/B)] = η G − η² Q。  (7)

熵流（进入热浴）J_S = q / T，T=η。总熵产率

  **σ = dS_sys/dt + q/T = dS_sys/dt + G − η Q ≥ 0。** (8)

稳态 dS_sys/dt = 0 时 σ = G(1−η/η_c*) ≥ 0，η→η_c* 时 σ→0：
**临界减速（critical slowing down）伴随熵产率趋零**——耗散趋近
零是平衡相变点的特征。这给出可检验预测：

* **P4**：稳态 σ（直接用记录的 G、trC、trH 按 (7)(8) 计算）应随 η
  单调下降并在 η_c 附近接近最小值；越过 η_c 后体系跳到无序平台，
  G、Q 重排，σ 重新回升。σ(η) 呈**尖点/V 形**。
* **P5（磁化率类比）**：S 的时间/种子涨落 χ_S = Var_seed(S)（及
  Var_t(dS/dt)）在 η_c 附近取极大——临界涨落。

### 2.3 S 用直方图熵代理时的精确性说明（重要）

式 (8) 对 **Gibbs/微分构型熵** S_G = −∫p(θ)ln p(θ)dθ 严格成立。
实验测的是**权重标量取值的一维直方图熵**，它忽略参数间相关结构，
是 S_G 的粗粒化代理（coarse-grained proxy），与 Langevin 账本不在
同一数学对象上。因此 σ 的检验按两级强度报告：

* 强检验（不依赖 S 定义）：q/T = G − ηQ 的 η 标度与 η_c* 过零
  （P1/P2/P4 的热流部分，只用 G、H、Σ）；
* 弱检验（依赖代理）：含 dS_hist/dt 的完整 σ 平衡，只作趋势比较，
  不声称等式精度。任何结论叙述必须区分这两者。

## 3. dS/dt 为什么噪声大：方差来源分解

观测到的 dS/dt 抖动有三个独立来源，实验设计将三者分开测量：

1. **直方图估计误差（测量噪声，非物理）**
   N 个权重、L 个 bin 的插件式多项分布熵估计：
   * 偏差（Miller–Madow）：Bias(Ŝ_nats) ≈ −(L_occ−1)/(2N)；
   * 方差：Var(Ŝ_nats) ≈ (1/N)[Σ_i p_i(ln p_i)²
     − (Σ_i p_i ln p_i)²]。
   phase5 同时记录解析公式值、Miller–Madow 偏差，以及对同一权重张量
   做 K=20 次多项自助的经验 std。N≈1.9×10⁴、L=100 时该项 std 约
   10⁻⁴–10⁻³（归一化单位），**比跨种子/跨时间涨落小一个数量级以上**
   则可排除"噪声来自估计器"。
2. **有限批量梯度噪声（物理，扩散项）**
   权重单步扩散协方差 η² Σ/B，经 ΔS ≈ s^T Δθ 传播：
     Var_batch(ΔS) ≈ η² s^T (Σ/B) s。
   高频、零均值，随 η²/B 缩放，在 η 大时增强。
3. **慢动力学/跨种子涨落（物理，临界涨落）**
   不同初始化在分叉点附近选择不同熵平台，Var_seed(S) 即磁化率类信
   号，按 P5 应在 η_c 处取峰。

分析脚本输出三者的数值表与随 η 的曲线（`entropy_noise.png`）。

**P6**：若"噪声大"主要是来源 1，自助/解析 std 会占主导且与 η 无关；
若是来源 2，其方差 ∝ η²；若是来源 3，峰值锁定 η_c。数据将区分。

## 4. 假设与已知失效处（不做超出假设的主张）

1. **优化器是 AdamW，不是朴素 SGD。** AdamW 的更新为
   θ←θ−η m̂/(√v̂+ε)−ηλθ，等价于在自适应度规 g̃=(diag v̂)^{1/2} 下、
   逐参数有效温度 T_i ∝ η/√v̂_i 的非均匀 Langevin。式 (1)(8) 的
   *结构*（−η 漂移 + η² 噪声修正、热流账本）保持，但单一 T、
   各向同性 η_c* 公式是近似；P2 的 η_c* 数值一致将因此是近似的、
   数量级检验而非精确等式。这是本理论检验的首要 caveat。
2. **权重衰减**：AdamW 的 λ 项把有效能量改为
   U_eff = L_data + (λ/2)‖θ‖²；phase5 的 probe 梯度含该项（与训练
   完全一致），账本对 U_eff 成立。
3. **η² 展开要求 ηλ_max(H) 小**；η=0.08–0.15 区域高阶项不可忽略，
   发散 run（NaN）记为高 η 相的真实事件，不参与 η_c/β 数值拟合。
4. **S 是一维标量直方图熵**（§2.3），不是完整构型熵；LAR 任务已
   表明谱几何与泛化的关系是架构特异的，不把直方图熵等同于理论中
   的 S_G。
5. β 的平均场预测 1/2 是基准而非结论；若数据给 β≈0.26，结论是
   "平均场不足"，不反向硬套。
